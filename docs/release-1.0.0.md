# 1.0.0 社区发布准备

核对日期：2026-10-30。目标仓库：`longhaiqwe/longhai-podvoice`。此文件记录候选准备，不表示已通过官方审核。

## 本次修改

- 构建只生成发布资产，移除个人机器路径及构建后自动覆盖笔记库的行为。
- 将离线对齐工作进程源码嵌入 `main.js`，通过 Node.js 标准输入执行；标准安装无需额外的 `speech-timing.cjs`。Node.js、FFmpeg、sherpa-onnx 和模型仍由用户自行安装。
- 补充外部 JSON 类型、模板对象／请求头校验、未知异常的文字处理，以及异步操作失败反馈。按钮 HTML 使用宿主提供的清理函数。
- 使用官方 ESLint 推荐规则，保留现有按需加载方式；9 处 CommonJS 加载分别注明延迟加载桌面 API、兼容 Electron remote 或加载已打包 diff 的理由，未关闭整类规则。
- 声明桌面专用，修正文档中的移动兼容、模型素材包含范围、联网服务和凭证存储说明。
- 添加持续集成、标准资产安装测试与外部响应边界测试。

## 文档与代码不一致之处

1. 原 README 和 manifest 声称支持移动端，但离线对齐及系统目录选择使用 Node.js／Electron。候选按桌面专用申报；Windows、Linux 尚无本轮实机验收证据。
2. 原安装说明要求额外安装 `speech-timing.cjs`，而社区安装器只下载三个标准文件。候选把脚本打包进 `main.js`。
3. 原说明称参考音频为插件内置，实际仅内置服务端路径和参数。模型权重、参考音频及其授权不包含在插件 MIT 许可内，也不在本次发布资产中。
4. 原隐私说明只列火山引擎和 GPT-SoVITS，代码还支持 MiniMax、Replicate 和自定义 HTTP 服务；已补充对应请求和可能的服务商费用。
5. 原说明称凭证只安全保存在本地，实际为插件数据文件中的未加密值，请求时发送给配置的服务，且可能随库同步。已按实际行为更正。
6. 原 README 链接到未跟踪的本地验证记录，公开仓库无法打开；已改为明确说明该记录未公开。

## 验证与边界

- JavaScript 测试：200 项通过；Python 测试：10 项通过。
- TypeScript 类型检查和生产构建通过。
- npm 依赖审计：0 漏洞。更新 esbuild，并通过 override 将仅开发工具使用的 moment 固定到已修复的 2.31 系列；不改变宿主内置的 moment。
- 官方推荐 ESLint：0 错误、23 警告。警告包括 DOM 创建建议、语言检测、窗口计时器、文件删除接口、设置搜索接口和界面大小写等；保留当前实现，等待官方预扫描进一步核对。
- 安装测试仅复制 `main.js`、`manifest.json`、`styles.css`，验证打包后的代码能传递工作进程源码、接收模拟识别结果，并在独立 Node.js 进程启动脚本。它不是 Obsidian 真机播放或语音识别准确率验收。
- 本轮未操作日常库安装。宿主 CLI 未启用，当前安装器提示版本较旧，真实宿主安装／升级验收尚未完成。
- 常见密钥格式扫描未发现匹配；这不等同于完整秘密检测证明。
