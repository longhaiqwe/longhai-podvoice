# Longhai PodVoice (有声听笔记插件)

**Longhai PodVoice** 是为你打造的 Obsidian 播客级有声笔记插件，与专注播客转写文字稿的 **`Longhai Podscript`** 形成完美的双向闭环：

* 🎙️ **Longhai Podscript**：播客音频 ➔ 结构化 Markdown 笔记（音频转文字）
* 🔊 **Longhai PodVoice**：Markdown 笔记 ➔ 播客级有声沉浸听读（文字转语音）

默认搭载**墨问（Mowen）同款【火山引擎 / 豆包大模型语音合成 (TTS 2.0)】**，采用“一次生成，本地持久化”的高性价比架构，配合**单笔记覆盖防膨胀**与**一键缓存管理**，完美兼容**电脑端与手机端**。

---

## 🌟 核心特性

1. **墨问同款火山引擎豆包语音大模型**：
   - 字节跳动火山引擎企业级语音模型（与剪映、抖音、番茄小说同一套自研语音体系）。
   - 预设 10 款经典音色：通用知性女声（灿灿同款体系）、灿灿（活力爆款）、通用磁性男声、知识科普讲解专栏男女声等，咬字温和自然、顿挫呼吸感真实，久听不累。
   - 支持自定义 Voice Type 代码、语速/音量/音调调节。

2. **存储空间防膨胀与生命周期管理（彻底解决 Vault 体积膨胀）**：
   - **单笔记覆盖模式（默认开启）**：无论同一篇笔记修改重新生成多少次，系统直接覆盖替换（`[笔记名].mp3`）并自动清理历史旧版本，每篇笔记在本地永远只保留最新一份音频！
   - **实时容量统计**：设置面板清晰展示当前已生成音频数量与占用体积（MB/KB）。
   - **清理孤立音频**：一键扫描并清理那些原 Markdown 笔记已被删除的无效音频残留。
   - **一键清空全部音频**：听完后随时一键清空音频释放磁盘，笔记文本完好无损，需要听时再按需生成。

3. **笔记 ⇄ 音频双向强关联**：
   - **笔记 ➔ 音频**：
     - 生成后自动在当前笔记的 YAML Frontmatter 中写入 `audio: "[[TTS Audio/笔记名.mp3]]"` 属性。
     - 支持可选在笔记正文顶部或底部自动插入原生嵌入播放组件（`![[...]]`）。
     - 支持在笔记内一键执行命令**「Longhai PodVoice：播放当前笔记关联的语音」**，无需重复合成。
   - **音频 ➔ 笔记**：
     - 专属播放弹窗顶部内置“📄 关联笔记”卡片与“打开笔记”按钮。
     - 即使直接从 `TTS Audio` 目录播放音频，插件也能根据文件名自动反查并定位到对应的 Markdown 笔记，点击一键跳转打开！

4. **双端无缝支持（手机端 + 电脑端）**：
   - 全面兼容 macOS、Windows、iOS、iPadOS 和 Android。
   - 网络请求统一采用 Obsidian 原生 `requestUrl`（绕过移动端跨域限制）。
   - 音频文件存储走 Obsidian 原生接口，配合 iCloud 自动在 Mac 与 iPhone 间无缝同步。

5. **智能 Markdown 文本清洗**：
   - 自动滤除 Frontmatter 元数据、标签（#tag）、URL 链接、图片、嵌入块及 HTML 注释。
   - 优化英文缩写连读（如 API、SDK 自动留白分隔），标题与无标点行尾智能补充停顿。

6. **增强播放控制器**：
   - 0.75x / 1.0x / 1.25x / 1.5x / 1.75x / 2.0x 快捷倍速切换。
   - ⏩ 快进 15 秒 / ⏪ 快退 15 秒快捷按键。
   - 一键跳转原笔记、打开音频文件、复制路径、复制嵌入代码。

## 🚀 快速上手与配置

### 1. 安装方式

* **方式 A（Obsidian 社区市场，官方上架后推荐）**：
  打开 Obsidian ➔ 设置 ➔「第三方插件」➔「社区插件市场」➔ 搜索 `Longhai PodVoice` ➔ 点击安装并启用。
* **方式 B（BRAT 测试版安装，手机与电脑通用）**：
  安装并启用社区插件 **BRAT** ➔ 打开 BRAT 设置 ➔ 点击 `Add Beta plugin` ➔ 输入 GitHub 仓库地址 `longhaiqwe/longhai-podvoice` 即可自动拉取最新测试版。
* **方式 C（手动安装）**：
  从 GitHub Releases 下载最新的 `manifest.json`、`main.js`、`styles.css`，解压至你的仓库目录：
  ```text
  <你的仓库>/.obsidian/plugins/longhai-podvoice/
    ├── manifest.json
    ├── main.js
    └── styles.css
  ```
  在 Obsidian 设置中进入「第三方插件」，启用 **Longhai PodVoice**。

### 2. 火山引擎凭证配置（墨问同款）
1. 前往 [火山引擎控制台](https://console.volcengine.com/speech) 开通**语音技术 - 语音合成 (TTS)** 服务；
2. 在控制台创建应用，获取你的 **App ID** 与 **Access Token**（或 API Key）；
3. 打开 Obsidian 设置 ➔ 找到 **Longhai PodVoice**；
4. Provider 选择 **火山引擎 (豆包大模型语音 - 墨问同款)**：
   - 填写 **App ID**
   - 填写 **Access Token / API Key**
   - Cluster ID 保持默认 `volcano_tts` 即可
   - 选择你心仪的音色（推荐“通用知性女声”或“灿灿”）
5. 点击下方 **「▶ 试听测试语音」** 按钮，验证连接与音质。

### 3. 避坑建议（保持 Obsidian 极速秒开）
建议在 Obsidian 设置 ➔ **「文件与链接 ➔ 已排除的文件 (Excluded files)」** 中，添加 `TTS Audio` 目录。
这样 Obsidian 在启动、建立全文索引、全局快速搜索（`Cmd + O`）和关系图谱时会**完全跳过该音频目录**，保证即便保存了大量音频，Obsidian 也依然像羽毛一样轻盈秒开！

## 🎧 使用指令

* **生成当前笔记语音**：
  - 点击左侧侧边栏新出现的 **耳麦图标**；
  - 或按 `Cmd/Ctrl + P`，输入 `Longhai PodVoice：生成当前笔记语音并保存到本地`；
  - 或在左侧文件列表右键笔记，点击 `听笔记：生成该笔记语音并保存`。
* **播放已关联语音**：
  - 在笔记中按 `Cmd/Ctrl + P`，输入 `Longhai PodVoice：播放当前笔记关联的语音`；
  - 或在左侧文件列表右键笔记，点击 `听笔记：播放该笔记关联语音`。
* **为选中文本生成语音**：
  - 选中笔记中的部分文字，右键菜单点击 `Convert selected text to speech`。

## 🔒 网络服务与隐私声明 (Privacy Disclosure)

本插件尊重并保护用户隐私，遵守 Obsidian 官方社区插件安全与隐私规范：

1. **按需数据发送**：仅在用户主动触发语音生成或试听时，插件才会将当前笔记清洗后的文本通过 HTTPS 加密传输至用户配置的第三方语音合成服务接口（如字节跳动火山引擎 `openspeech.bytedance.com`）。
2. **零隐私采集与跟踪**：本插件不包含任何统计代码、遥测（Telemetry）、跟踪器或第三方分析 SDK，不会收集任何用户身份信息或未主动选择的笔记内容。
3. **本地凭证存储**：你的 App ID、API Key / Access Token 仅安全保存在本地仓库的 `.obsidian/plugins/longhai-podvoice/data.json` 中，绝不会上传至任何中转服务器。
